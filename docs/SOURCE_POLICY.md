# 第三方职位来源策略

## 目标

严格保留远程产品岗位筛选条件，优先发现中小企业机会。第三方平台与项目官网招聘并行接入；是否保留某一来源由管理页面单独控制。

## 已接入来源

- web3.career：通过其公开 API 获取远程职位。
- remote3.rss：通过 Remote3 公开 RSS 获取远程 Web3 职位；仅下载产品岗位详情页，避免无关抓取。
- himalayas.api：通过 Himalayas 公开远程职位 API 按产品经理关键词和最新顺序查询。
- remoteok.api：通过 Remote OK 公开职位 API 获取近 7 天产品经理岗位。
- jobicy.api：通过 Jobicy 公开远程职位 API 获取近 7 天产品经理岗位。

全部来源都显示在管理来源页面的网站职位来源区。只能屏蔽或重新启用，不能从管理页删除历史数据；每次只写入发布时间在近 7 天内的职位，缺少发布时间或早于 7 天的记录不进入筛选队列。

## 项目官网招聘

已接入并现场验证公开职位接口的官网来源共 16 条：Coinbase、Consensys、Fireblocks、Ripple、Nansen、BitGo、Figment、Gemini、Phantom、OpenSea、Uniswap Labs、Mysten Labs / Sui、Alchemy、Gate、Binance、Kraken。

头部交易所不再按公司名称全局丢弃。每条官网来源默认启用，用户可在管理页面中单独屏蔽或重新启用；屏蔽不会删除历史职位。官网接口仅读取最新一小批岗位，并且只有发布时间在近 7 天内的职位才会写入筛选队列。

## 暂不接入的平台

- CryptoJobsList：公开声明允许抓取，但现场访问被防护服务拒绝；未获得稳定访问方式前不接入。
- Cryptocurrency Jobs：其公开内容使用声明不足以支持将职位正文送入本地模型复核；在获得明确授权或合规接口前不接入。

## 来源试运行与淘汰

每个第三方来源先试运行 7 天，统计新增产品岗位数、最终合格岗位数、重复率和异常率。无稳定合格产出的来源在仪表盘中屏蔽，不为了数量降低筛选标准；屏蔽不会删除历史数据。
